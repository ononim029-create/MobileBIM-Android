# Mobile BIM — Android

Мобильный BIM/CAD-редактор для Android. Технический прототип **v0.8**.

## Состояние

- Kotlin BIM-ядро: 34 проверочных сценария выполнены в изолированной среде.
- Android APK: **ещё не собран и не проверен**.
- Интеграция с Revit/TARQELIO и Archicad отложена.

## Добавление исходников v0.8

Чтобы запустить первую сборку, загрузите подготовленный файл `MobileBIM-Android-v0.8-source.zip` в **корень** репозитория под **точно таким именем**: **Add file → Upload files → Commit changes**. Распаковывать ZIP не требуется — workflow умеет распаковать его во время сборки.

Вместо ZIP можно загрузить исходники напрямую, тогда `settings.gradle.kts`, `app/` и `core/` должны находиться в корне репозитория.

## Сборка APK

После загрузки исходников перейдите в **Actions → Build Mobile BIM Android**. При успешных шагах `:core:test` и `:app:assembleDebug` GitHub выдаст файл `MobileBIM-v0.8-debug-apk` в блоке **Artifacts**. При ошибке проверьте лог Actions: отсутствие файла APK **не означает** успешную сборку.

Артефакты тестовых сборок хранятся 14 дней. Публичный релиз и подписанный установщик пока не создавались.
